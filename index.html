3. Free-source references

  • Sleeper API documentation — public read-only endpoints and current NFL state/player directory.
  • nflverse data schedule — play-by-play and player/team stats update nightly after game days; injury and depth-chart datasets update daily.
  • NFL official injury reports — confirm practice status and final game designations.
  • NFL official statistics — verify player and team production.
  • Pro-Football-Reference — historical game logs and team splits; verify season and freshness.
What this does not yet do: run in the background, guarantee browser API access, or automatically derive reliable coverage-scheme and injury conclusions. It calculates observed custom-scoring points from available player box-score fields and prepares a research brief. For high-confidence recommendations, verify the linked injury and matchup sources before kickoff. If browser requests are blocked, the page shows the error and the report still generates a useful research brief without fabricated stats.
